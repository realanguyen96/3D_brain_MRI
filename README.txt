This project is an attempt to replicate a study in Nature Comm by Vogelstein et al. (2021). https://doi.org/10.1038/s41467-021-23102-2

Compared conventional feature selection (FS) methods in machine learning (ML) to 3D Convolutional Neural Network (CNN) deep learning for 3D brain MRI classification (0 = control, 1 = ASD) and overall troubleshooting/proofreading. 

The difference in predicting result might be due to resizing data but overall, our proposed ML pipeline shows 60% of accuracy in predicting ASD positive cases.

Datasets were downloaded from https://fcon_1000.projects.nitrc.org/indi/abide/abide_II.html and transformed into numpy array but the original data was too heavy for GitHub, it won't be uploaded here
